# Hermes OS

> An operating system for disciplined trading decisions.

---

# Mission

Hermes OS — это исследовательская платформа для алгоритмического анализа рынка, управления риском и повышения качества торговых решений.

Главная цель проекта — не предсказывать рынок, а принимать решения, основанные на статистическом преимуществе, дисциплине и проверяемых правилах.

---

# Vision

Hermes OS должен стать системой, которая:

- анализирует рынок лучше человека;
- никогда не действует эмоционально;
- объясняет каждое свое решение;
- постоянно обучается на накопленной статистике;
- помогает трейдеру соблюдать собственную стратегию.

---

# Core Principles

## 1. Transparency

Никаких "черных ящиков".

Каждое решение должно быть объяснимо.

---

## 2. Simplicity

Если правило можно сделать проще — оно должно быть проще.

---

## 3. Research First

Любая новая идея сначала становится гипотезой.

Гипотеза проходит:

1. формулировку;
2. тестирование на истории;
3. проверку в режиме советника.

Только после этого становится частью системы.

---

## 4. Quality over Quantity

Лучше одна качественная сделка, чем десять посредственных.

---

## 5. No Prediction

Hermes OS никогда не пытается угадывать будущее.

Он оценивает текущее состояние рынка и вероятность того, что торговое преимущество существует.

---

## 6. T-Bank First

Первая версия системы работает с рыночными данными через API Т-Банка.

Первый инструмент — доступный в Т-Банке NEO-актив, связанный с динамикой биткоина. Он следует за BTC близко, но не обязан повторять его цену абсолютно точно. Технически неоактивы считаются фьючерсами, поэтому конкретный тикер с `NEO` и идентификатор инструмента нужно искать среди фьючерсов через API до реализации торговой логики.

После проверки архитектуры добавляются фьючерсы на нефть, пару доллар/рубль и индекс Мосбиржи.

---

# Long-term Goal

Создать платформу, которая объединяет:

- анализ рынка;
- управление риском;
- журнал сделок;
- исследование новых гипотез;
- анализ поведения трейдера;
- автоматическую генерацию ежедневных отчетов.
