# Hermes OS

> **An operating system for disciplined trading decisions.**

Hermes OS is an open research platform for building transparent, rule-based and statistically validated trading systems.

The project focuses on **decision quality**, not prediction.

---

## Mission

Hermes OS helps traders make disciplined decisions based on:

- objective market analysis;
- transparent trading rules;
- statistical validation;
- strict risk management;
- continuous research.

The system is designed to reduce emotional decision-making and improve long-term consistency.

---

## Philosophy

Hermes OS follows one simple idea:

> **We optimize decisions, not predictions.**

Every rule must be:

1. Clearly defined.
2. Testable.
3. Statistically validated.
4. Explainable.

If a rule cannot be tested, it does not belong in the system.
